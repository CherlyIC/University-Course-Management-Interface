#  University Manager

A university course management interface for supervisors to create, view, edit and delete courses.

# Credential to login

> Login with `admin@example.com` 
password: `adminpassword123`


## Tech Stack

- **React + Vite**
- **Tailwind CSS**
- **Axios**
- **React Router DOM**

---

## Getting Started

# 1. Clone the repo
# 2. Install dependencies
npm install

# 3. Run locally
npm run dev
